# 商品美編需求單

讀取使用者指定的商品資料，交付一份繁體中文需求單。未指定輸出位置時存到專案的 `outputs/`；使用者指定位置或格式時依其要求。

## 內容

- 商品摘要：名稱、SKU、價格、規格、配送與客群，附來源檔案及段落。
- 已確認賣點：每一項附來源，把未有證據的想法放到待確認區。
- 前三張銷售圖：逐張寫出目的、主標、可用副文案、視覺方向及需要的素材。
- 待確認與缺件：列出缺少的數字依據、商品資訊與圖片，說明影響哪一張圖或哪句文案。
- 交接檢查：核對各處價格與規格一致，品牌與商品沒有串用；未取得的照片、生成圖或宣稱不可描述成已完成或已驗證。

這個練習預設前三張圖，使用者指定其他張數時依其需求。主標應提出有來源支持的購買理由，不把「想寫」等同「已確認」。每次新商品重新讀取該商品的資料，不沿用前一商品數字。

回報輸出檔案與仍需補齊的資訊。產出是美編需求單，不能把它當成已生成圖片、完成排版或正式上架。
