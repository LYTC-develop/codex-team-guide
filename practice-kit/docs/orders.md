# 訂單與收款練習

全部為虛構資料。幣別：新台幣；期間：2026-09-01 至 2026-09-07。

## 對帳規則

- 每筆應收 = 訂單金額 − 已核准退款。訂單金額已含運費；本題不另計稅費。
- 收款欄是扣除退款後的淨收款，本題沒有平台手續費或跨期入帳。
- 以訂單編號完全一致配對，同編號多筆收款應加總。
- 應收為正、沒有收款的訂單列「未收」；有收款但小於應收列「少收」。
- 無對應訂單的收款獨立列出，不能拿去抵銷其他訂單的短收。
- 檔案內沒有的交易原因不得推測成事實。
