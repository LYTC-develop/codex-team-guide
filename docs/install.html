從零安裝 Codex

依序完成下載、登入與開啟資料夾。已經裝好的夥伴，可以直接從步驟 3 開始。

  1. 到官方入口下載並安裝

    開啟官方安裝頁，選擇符合工作電腦的版本，下載後開啟安裝檔，依畫面提示完成。

    官方下載與安裝入口 ↗

    目前官方安裝頁以「ChatGPT desktop app」提供入口，安裝後可選 Codex。若公司已提供 Codex 應用程式，直接開啟使用即可。

  2. 登入，選擇 Codex

    開啟應用程式，用公司指定的 ChatGPT 帳號登入。在工作模式選單中選擇 Codex，建立新任務。入口名稱可能隨版本調整。

    使用 ChatGPT 帳號登入即可開始這堂課；看到 API 金鑰登入選項時，不需要為了練習改走那條路。

  3. 下載並解壓縮練習包

    下載練習包 ↓

    解壓縮後，找到 practice-kit 資料夾。裡面應該有 README.md 和 docs；另一個 .agents 資料夾可能被系統隱藏，保留原樣即可。

  4. 在 Codex 開啟這個資料夾

    在新增專案或開啟資料夾的入口，選取解壓縮後的 practice-kit，再於這個專案內建立任務。要選資料夾，不是 ZIP 檔。

    貼上這段，確認準備完成

    請讀取這個專案的 README.md 與 docs/product-a.md，告訴我商品名稱、價格，以及這次練習要完成什麼。先確認資料，不要開始製作。

    確認成功：Codex 能讀到「日常蕎麥麵 4 入組」與「299 元」。這表示它已經能讀取你的工作資料。

找不到檔案或 Codex 入口？

找不到檔案：確認 ZIP 已解壓縮，且選的是內層的 practice-kit；任務也要建立在這個專案中。

沒有 Codex 入口：確認登入公司指定帳號，並依官方說明更新應用程式；仍無法使用時，請管理員確認使用權限。
