從零安裝 Codex

先安裝、登入，再完成工作設定。第 5 章會帶你連接 GitHub、取得公司專案，第 6 章再開始美編任務。

  1. 下載並登入桌面應用程式

    開啟官方安裝頁，下載符合你電腦的版本，開啟安裝檔並完成安裝，再用公司指定的 ChatGPT 帳號登入。

    官方下載與安裝入口 ↗

    目前官方頁面稱為 ChatGPT desktop app，內含 Codex 入口。已安裝公司提供的 Codex 應用程式，可直接登入。

  2. 在應用程式裡打開「設定」

    先點一下 Codex 視窗，讓它成為目前使用的應用程式，再按下面的快捷鍵。

    Mac⌘ Command ＋ , 逗號

    WindowsCtrl ＋ , 逗號

    你應該看到：Settings／設定面板，裡面有 General、Personalization 等分類。

  3. 設定我們希望 Codex 怎麼工作

    在設定面板選 Personalization／個人化，找到 Custom instructions／自訂指示，貼入下面這段。已有公司指示時，保留原文並追加。

    貼到「自訂指示」欄位

    請使用繁體中文，先讀取我指定的資料，再執行工作。需要交付文件時，請實際存檔，完成後提供可開啟的檔案連結與路徑。沒有依據的內容列為待確認；需要我操作介面時，清楚說明位置與下一步。

    若介面有 Save／儲存，按下儲存；離開再回到這個設定，確認文字仍在。

    這是平常工作的偏好。接下來實作時，教練對話還會要求 Codex 分階段帶你操作。

  4. 確認長段文字怎麼送出

    在 General／一般 找到與 multiline prompts／多行提示 相關的送出設定，確認 Enter 是換行還是送出。本教材統一使用輸入框旁的送出按鈕，貼完整段再送出。

    完成後關閉設定，回到對話主畫面。在模式選單選擇 Codex；若你用的是獨立 Codex 應用程式，保持在目前介面。

這一章完成：已登入 Codex、自訂指示已保留，知道怎麼貼完整段文字並送出。接著看差異與名詞，再到第 5 章取得公司專案。

介面名稱跟教材不同？

這份教學以官方目前的桌面版說明為準。設定快捷鍵若沒有反應，從應用程式選單找 Settings；也可在 Settings → Keyboard Shortcuts 檢查自訂快捷鍵。沒有 Codex 入口時，請公司管理員確認帳號、版本與使用權限。

入口核對於 2026-09-17：官方設定說明 · 官方快捷鍵。這裡是操作指引，並非你的電腦已完成設定的證明。
