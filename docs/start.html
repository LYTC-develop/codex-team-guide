開始之前

這份教材的目標很簡單：讓你能把一件工作交給 Codex，拿到可以打開、檢查與交接的成果。

這次會完成什麼？

商品資料→Codex 依照團隊方法整理→美編需求單

需求單會包含商品賣點、前三張圖的規劃與待補資料。你可以沿用同一個方法，再做下一個商品。

先準備這三樣

  • 一台工作電腦用電腦安裝桌面應用程式，並保留一個放練習資料的資料夾。
  • 公司指定的 ChatGPT 帳號使用有 Codex 使用權限的帳號；若登入後沒有入口，先向公司管理員確認帳號與方案。
  • 一份練習資料下一章會下載。全部是虛構商品與訂單，可以直接跟著操作。

你需要會的：下載檔案、解壓縮、選取資料夾，以及把任務貼進對話。這次不需要寫程式或準備 API 金鑰。

先用本機練習包即可。GitHub 帳號與團隊專案存取權，等到要共同維護 Skill 時再由公司安排。
