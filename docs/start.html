開始之前

這份教材的目標很簡單：讓你能把一件工作交給 Codex，拿到可以打開、檢查與交接的成果。

這次會完成什麼？

商品資料→Codex 依照團隊方法整理→商品首圖與改價版本

先用公司的美編專案與虛構練習資料製作一張圖，再改價格、核對前後版本。

先準備這三樣

  • 一台工作電腦用電腦安裝桌面應用程式，並保留一個放練習資料的資料夾。
  • 公司指定的 ChatGPT 帳號使用有 Codex 使用權限的帳號；若登入後沒有入口，先向公司管理員確認帳號與方案。
  • 有公司專案權限的 GitHub 帳號先接受公司的組織邀請。第 5 章會帶你登入並取得美編工作包。

你需要會的：登入帳號、選取資料夾，以及把任務貼進對話。這次不需要寫程式或準備 API 金鑰。

公司美編專案是私人 Repo，要先有存取權。圖片實作另需可用的圖片工具與額度。
