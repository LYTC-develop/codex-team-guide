跟 ChatGPT Web 差在哪

你已經會用對話討論工作。這次改用 Codex，要練習的是讓 AI 讀取工作資料、沿用團隊方法，並把成果存回專案。

原本常見的做法貼上資料 → 拿到回答 → 自己搬回工作

→

這次要練習的做法開啟專案 → 讀檔與操作 → 留下可用成果

01

Doc 把背景留下來

把商品資料、規範與決策放進專案文件，讓 AI 有依據地工作，下次也能接續。

例如：讀訂單與收款，找出差異。

02

Skill 把方法重複用

把做得好的流程整理成可重用的工作指引，自己下次用，也能交給同事用。

例如：每個商品都用同一套美編交接流程。

03

Computer use 讓 AI 動手操作

透過可用的操作工具，讓 AI 查看畫面、點選與填寫，完成跨網頁或軟體的工作。

例如：依商品文件，填好上架草稿。

這裡的 Doc 泛指專案文件。這三項是本次導入的重點，並非 Codex 獨有；實際能力依版本、工具與授權而定。

這堂課先做前兩件：讀商品 Doc、用 Skill 做出美編需求單。完成後，延伸練習再體驗操作表單。
