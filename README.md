# 開始用 Codex 工作

**[開啟教學網站 →](https://lytc-develop.github.io/codex-team-guide/)** · **[下載練習包 →](https://lytc-develop.github.io/codex-team-guide/downloads/codex-practice-kit.zip)**

給已經使用 ChatGPT 的同事。先懂三個觀念，再選一個工作實作；名詞遇到時再查。

## 先懂三件事

| 觀念 | 用在工作上 |
|---|---|
| **Doc：把背景留下來** | 把商品資料、工作規範與決策整理成專案文件，讓 AI 讀取、更新與接續。 |
| **Skill：把方法重複用** | 把驗收過的流程整理成可重用指引，自己下次用，也讓同事沿用。 |
| **Computer use：讓 AI 動手操作** | 透過可用的操作工具查看畫面、點選與填寫，完成網頁或軟體操作。 |

這裡的 Doc 泛指專案文件。這三項是本次 Codex 導入的工作重點，並非 Codex 獨有功能；實際能力依版本、工具與授權而定。

我們要練習的是：**開啟專案 → 讀檔與操作 → 留下可用成果。**

## 選一個工作，直接試試

下載練習包、解壓縮，在 Codex 開啟 `practice-kit` 資料夾。[練習說明](practice-kit/README.md) 有可以直接貼上的任務。資料全部為虛構範例。

| 練習 | 你會拿到什麼 | 怎麼知道做對了 |
|---|---|---|
| **Doc：訂單與收款對帳** | 差異清單，附訂單編號與計算方式 | 找到少收、未收與無對應訂單的款項；網站可展開核對答案。 |
| **Skill：商品美編需求單** | 兩個商品各自的賣點、前三張圖規劃、待補資料 | 同一份 Skill 能重用，不混用兩個商品的價格與規格。 |
| **Computer use：填寫商品表單** | 正確預覽與可下載商品草稿 | AI 實際操作了表單，下載檔案可打開；不是只給操作說明。 |

第三題先確認操作工具可用；沒有時先做前兩題。[商品表單練習場](https://lytc-develop.github.io/codex-team-guide/practice.html) 不連正式商店，草稿只在目前頁面暫存，下載後才有可保留的檔案。

## 遇到再查的名詞

- **GitHub／Repo**：GitHub 保存版本、供大家共同維護；Repo 是其中一個專案及其檔案與版本紀錄。例如「在這個 Repo 更新美編 Skill，讓同事取得同一份方法」。
- **API**：系統給程式讀取資料或執行操作的介面。例如「先找 API、匯出檔或現成工具，不用每張都截圖辨識」。
- **MCP**：AI 連接工具與資料的共同規格。例如「確認有沒有能讀試算表的工具，缺少什麼連接或授權」。
- **Clone／Pull／Push**：首次取得專案、整合遠端更新、把已提交的變更送到遠端。下載 ZIP 可以練習，持續同步團隊版本再學這段流程。
- **AGENTS.md**：給 Codex 的專案工作指引，例如資料在哪、用什麼流程、成果放哪。

不必先把名詞背完。第一個目標是留下能打開、能核對、下次能繼續使用的成果。
