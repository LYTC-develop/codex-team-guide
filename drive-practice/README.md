# 用 Codex 上傳 Drive、修改 Google Sheets

完整教學：https://lytc-develop.github.io/codex-team-guide/google-drive.html

1. 在 Codex 的 Plugins／外掛安裝並連接 Google Drive，登入自己的公司 Google 帳號。
2. 將本資料夾放在「文件／Codex工作區／drive-practice」。
3. 在 Google Drive 新增自己的「Codex練習」資料夾，開啟後複製資料夾網址。
4. 回 Codex 按 Mac Command＋O／Windows Ctrl＋O 開啟本資料夾；按 Command＋N／Ctrl＋N 建立 Local 新任務。
5. 將「開始教學.txt」整段貼入新任務，依教練引導貼上 Drive 資料夾網址。
6. 依序回覆「開始上傳」「我看到了，開始修改」「核對完成」。每次先親自檢查成果再回覆。

檔案：行政採購練習.xlsx、採購說明.txt、開始教學.txt。
所有資料皆為虛構。原始合計 1,250 元；修改 P-002 數量 3 → 5 後為 1,610 元。
不需要自行建立 Google Cloud 專案或 Cloudflare 設定。若公司禁止外掛授權，請公司管理員處理。
